# Правила проекта deploy-baremetal

## Кодировка PowerShell-скриптов (.ps1)

Любой файл `.ps1` в этом проекте, содержащий кириллицу (а это все скрипты с русскими сообщениями: `make-boot-usb.ps1` и т.п.), должен сохраняться как **UTF-8 с BOM** и с переводами строк **CRLF**.

Причина: скрипты запускаются на Windows под Windows PowerShell 5.1, который читает файлы без BOM в системной кодировке CP1251. Кириллица в UTF-8 при этом превращается в мусор, а отдельные байты (например `0x94` в букве «Д») декодируются как «умные» кавычки `"` — PowerShell считает их закрывающими ограничителями строк, из-за чего возникают каскадные ошибки парсера («Непредвиденная лексема ")"», «Непредвиденная лексема "}"»).

Правила при создании и правке `.ps1`:

- Всегда добавляй BOM (`EF BB BF`) в начало файла; не позволяй редактору/инструменту молча убирать его.
- Проверяй кодировку после правок: `file script.ps1` должен показывать `UTF-8 (with BOM)`, переносы — CRLF.
- Не используй в коде и строках «умные» кавычки (U+201C/U+201D/U+2018/U+2019) — PowerShell 5.1 трактует их как ограничители строк.
- Не пиши `$имя:` внутри строк в двойных кавычках — PowerShell трактует это как дисковую ссылку (как `$env:PATH`) и падает с «Недопустимая ссылка на переменную». Отделяй имя фигурными скобками: `${имя}:`. Проверяется `check-files.sh`.
- Быстрая проверка перед передачей на Windows: `head -c 3 script.ps1 | xxd` должен показывать `efbb bf`.
- При каждой правке `make-boot-usb.ps1` обновляй `$ScriptVersion` в шапке (формат `ГГГГ-ММ-ДД.N`) — версия выводится в баннере и шапке лога и служит контролем свежести копии на Windows-машине.
