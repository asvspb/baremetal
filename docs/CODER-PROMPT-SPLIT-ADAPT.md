## Окружение

- Работа на Linux (bash). Целевой диск `/dev/nvme0n1` ПРИСУТСТВУЕТ на этой машине.
- `sudo` НУЖЕН для dry-run-проверок (A0.2, A4 golden, S-H3 E2E). Но реальный
  запуск без `--dry-run` запрещён: скрипт сам блокирует его на не-Live системе.
  Никогда не используй `--force` и не запускай операцию на живом железе.
- Реальный прогон из Live-USB (A5.1) выполняет владелец — твоя зона: код и тесты.

## Железные правила (нарушение = переделка)

1. Один коммит = одна задача, формат `A1: split-home constants + Distr guard`.
   До любых правок — ветка `fix/split-adapt` (A0.1), не коммитить в `main`.
2. `set -Eeuo pipefail` сохраняется; после каждой правки `.sh` — `bash -n` и
   `shellcheck -S warning` (0 замечаний).
3. НЕ менять (инварианты не зависят от старой разметки): стартовый сектор p7
   `638709760`, UUID p7 `1b8e3e50-…`, целевая граница 200 GiB
   (`P7_SIZE_SECTORS=419430400`, `P7_END_SECTOR=1058140159`),
   `TARGET_SHRINK_GB=195`, `USED_LIMIT_GB=190`.
4. МЕНЯЕТСЯ (суть адаптации): раздел `P8 → P9`, конечный сектор нового раздела
   `100% → 1745784831s`, новые отпечатки `EXPECT_P7_SIZE_SECTORS=1107075072`
   и Distr (`1745784832` + PARTUUID).
5. Порядок миграции/сверки из SPLIT-SPEC (S1–S5) принят и НЕ пересматривается.
6. Не выходить за рамки задачи: без рефакторинга соседнего кода, перевода
   русских сообщений на английский, изменения UX. Запрещены правки `deploy.sh`,
   `make-boot-usb.*`, `templates/`, `autounattend`.

## Ключевые технические указания

- **A6**: `parted -s "$DISK" resizepart 7 "${P7_END_SECTOR}s"` заменить на
  `run parted ---pretend-input-tty "$DISK" resizepart 7 "${P7_END_SECTOR}s" <<< "Yes"`.
  Проверить на loop-образе: сжатие без интерактива, rc=0.
- **A1**: ввести `PART_SYS_ROOT="/sys/block/nvme0n1"` и читать через него
  `start`/`size` p7 и `start` p8 (behavior-сохраняющий приём — его переопределяет
  тест A4). Отпечаток Distr: `blkid -s TYPE` = `exfat`, `blkid -s PARTUUID` =
  `58c56411-…`, start из `${PART_SYS_ROOT}/nvme0n1p8/start` = `1745784832`.
- **A2**: `P9_END_SECTOR=$((EXPECT_DISTR_START - 1))` (= 1745784831);
  `parted -s "$DISK" mkpart "UbuntuHome" ext4 "${P9_START_SECTOR}s" "${P9_END_SECTOR}s"`
  — без `100%`. В `do_migrate_home` UUID для fstab брать с `$P9`.
- **A4**: golden регенерировать ТОЛЬКО после A1–A3 и A6:
  `sudo env SPLIT_HOME_TS=20260902-202633 bash split-home.sh --dry-run \
   > tests/fixtures/split-home-dry.golden 2>&1`.
  В diff с прежним эталоном — только геометрия/имена/цифры и строка resizepart.
