## Контекст (кратко, из код-ревью)

- `make-boot-usb.ps1` (2240 строк) содержит ВЕСЬ СКРИПТ ДВАЖДЫ: строки 1121–2240 —
  точная копия строк 1–1120. Второй `param()` в середине файла недопустим.
- Установка Windows через `wimlib-imagex apply` в `deploy.sh` не создаёт загрузчик
  (нет bcdboot/BCD) — система не загрузится. Решено переходить на установку
  Windows загрузкой ISO с Ventoy + autounattend.xml (задача T2.1, вариант A).
- Бэкап данных флешки перед разметкой молча проглатывает ошибки копирования
  и удаляет копию после восстановления без сверки — риск потери данных (T1.2, T1.3).
- Путь debootstrap в `deploy.sh` ставит систему без ядра (T2.3).
- GRUB ≥ 2.06 не запускает os-prober без `GRUB_DISABLE_OS_PROBER=false` (T2.2).
- Часть опций `deploy.conf` объявлена, но ни на что не влияет (T2.4).

## Окружение

- Работа на Linux (bash). PowerShell на этой машине НЕТ — `.ps1` проверяй только
  статически (см. «Проверки» ниже). Целевая платформа ps1 — Windows PowerShell 5.1.
- Права root не запрашивай; все проверки — статические и dry-run.

## Железные правила (нарушение = переделка)

1. Любой `.ps1` с кириллицей сохраняется как **UTF-8 с BOM + CRLF**. После каждой
   правки: `head -c 3 file.ps1 | xxd` → `efbb bf`; `file file.ps1` → `with BOM ... CRLF`.
   Никаких «умных» кавычек U+201C/U+201D/U+2018/U+2019 в коде.
2. `make-boot-usb.bat` (CP866 + CRLF) не трогать вообще.
3. `git init` и стартовый коммит — самый первый шаг (задача T0.1), до любых правок.
   Один коммит = одна задача, формат сообщения: `T1.2: safe backup in make-boot-usb.sh`.
4. Не выходить за рамки задачи: никакого массового рефакторинга, переименования,
   перевода русских сообщений на английский, изменения UX, которых нет в задаче.
5. Поведение «сухих» режимов (`--dry-run`) сохраняется рабочим во всех скриптах.

## Проверки после каждой правки

```bash
# .sh
bash -n SCRIPT.sh
shellcheck -S warning SCRIPT.sh

# .ps1 (статически, pwsh недоступен)
wc -l make-boot-usb.ps1            # ожидание задачи T1.1: 1120
grep -c SYNOPSIS make-boot-usb.ps1 # = 1
grep -c 'param()' make-boot-usb.ps1 # = 1
head -c 3 make-boot-usb.ps1 | xxd  # efbb bf
file make-boot-usb.ps1             # UTF-8 (with BOM), CRLF
python3 -c "d=open('make-boot-usb.ps1',encoding='utf-8-sig').read(); \
  print(d.count('{'),d.count('}'),d.count('('),d.count(')'))"  # пары равны

# dry-run сценарии (после задач, их касающихся)
bash deploy.sh --full --dry-run
bash split-home.sh --dry-run
```

После создания `check-files.sh` (T4.1) использовать его вместо ручных проверок.
